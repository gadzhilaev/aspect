## 2. Качество извлечения текста

Инструмент: **pypdf** `PageObject.extract_text()` локально.  
`pdftotext` / `tesseract` в среде **не установлены**. Внешний OCR/AI не подключался.

| Проверка | Результат |
|----------|-----------|
| Извлекается ли кириллица | **Нет** — 0 символов текста на всех страницах всех файлов |
| Порядок колонок | Не применимо (нет текстового слоя) |
| Знаки %, десятичные разделители | Не извлечены (нет текста) |
| Связь текст ↔ номер страницы | Структура страниц есть (1…N), но текст пуст |
| Таблицы / графики / image-страницы | **Каждая страница = изображение**; содержание таблиц и графиков в extract **не попало** |

### Вердикт по «прочитанности»

**Ни один документ нельзя объявить полностью прочитанным:** значимое содержание сейчас доступно только как растр.  
Для перехода к поиску/цитированию нужен **локальный OCR** (или поставка PDF с текстовым слоем). OCR на этом этапе **не** включался.

## 6. Что мешает перейти к импорту

1. **Нет текстового слоя** → нельзя строить нормальный поиск, цитаты со страницами, RAG-чанки, проверку «фрагмент ↔ страница».
2. Нет локального OCR в среде; внешний OCR/AI по условиям этапа не подключался.
3. Даты публикации в metadata ненадёжны (дата экспорта Quartz 2026-09-28).
4. Риск смешения **прогноза и факта** при OCR-ошибках таблиц/графиков — нужен отдельный QA после OCR.
5. Крупный `FI_Strategy_3Q26_…` (≈35 MiB, 27 стр.) потребует постраничного пайплайна и контроля качества.

### Рекомендуемый следующий шаг (вне объёма 2.1)

- Получить у источника PDF **с текстом**, или  
- Подключить **локальный** OCR (например tesseract + rus/eng) в offline-режиме, сохранить текст в `extracted/`, затем повторить карту содержания и разбор Policy Rate **с номерами страниц и цитатами**.
