## Ошибки и ограничения

1. Image-only PDF → только OCR; без OCR текст был 0 (этап 2.1).  
2. OCR-шум в кириллице (`He`/`NO`/`cTana`/`Hal`/`Toro`) — не авто-«чинить» числами.  
3. Таблицы и графики (стр. 2–3): conf ниже; числовые ряды графиков **не** извлечены.  
4. `winget --location` не изолировал бинарник; изоляция языковых данных — через `tools/tessdata`.  
5. Для `--tessdata-dir` нужны `configs/` (`tsv`), иначе Tesseract ищет config и падает тихо.  
6. Не смешивать прогноз банка (14% до конца 2026) с уже принятым решением ЦБ (пауза на 14%).
