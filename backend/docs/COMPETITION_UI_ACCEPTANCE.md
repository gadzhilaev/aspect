### Доступ с физического телефона (LAN)

Не настроено автоматически. Firewall не менялся, сайт в интернет не публиковался.

Если нужна проверка с телефона в той же Wi‑Fi:

1. Узнать LAN IP ПК (`ipconfig`).  
2. Запустить API/web с `--host 0.0.0.0` **только если** вы сами это решите (текущий стенд слушает `127.0.0.1`).  
3. На телефоне: `http://<LAN-IP>:5178`, а `VITE_API_BASE_URL` должен указывать на `http://<LAN-IP>:8018`.  
4. Не открывайте порты в интернет / не делайте port-forward без необходимости.
