# Мобильный дизайн — референс для web (итерация 1)

Исходные Figma-экраны Flutter-клиента в репозитории отсутствуют.  
Web опирается на ТЗ и фирменную палитру продукта «Контур».

## Палитра

| Роль | Значение | Использование |
|---|---|---|
| Brand red | `#E31C23` | CTA, акценты приоритета, активная навигация |
| Red soft | `#FCE8E9` | фоны бейджей high priority |
| Graphite | `#1F2329` | основной текст, сайдбар |
| Graphite mid | `#4A5160` | вторичный текст |
| Graphite line | `#D8DCE3` | границы |
| Surface | `#F4F5F7` | фон рабочей области |
| White | `#FFFFFF` | карточки, сайдбар light panels |

## Типографика

- Display / заголовки: **Manrope** (600–700)
- UI / тело: **Manrope** (400–500)
- Числа и метрики: tabular figures где возможно

Характер: деловой, плотный, без «мобильных» огромных hero-блоков.  
На desktop — информационная плотность руководителя: счётчики, лента, объяснимые статусы.

## Статусы claims (как в ТЗ)

| claim_type | Визуал |
|---|---|
| confirmed_fact | сплошной graphite badge |
| inference | outline |
| assumption | мягкий warning tone |
| estimate | demo/dashed accent |

Impact score и confidence **никогда не сливаются** в один индикатор.

## Навигация web vs mobile

| Web (desktop) | Mobile Flutter |
|---|---|
| Боковая навигация | Нижний tab / стек экранов |
| Таблицы и двухколоночные детали | Вертикальные карточки |
| Deep link `/companies/:id/events/:eventId` | Экран 14 события |

Web не копирует 18 мобильных экранов один-в-один.
